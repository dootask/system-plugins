# 备份与恢复审批数据

## 入口
- 「应用」→「审批」→「数据备份」（仅管理员可见）

## 能做什么
- **立即备份**：点按钮生成一个备份包（含审批数据库快照 + 所有上传的附件）
- **下载备份**：把备份包下载到本地保存
- **上传备份**：选择审批中心生成的 ZIP 或历史 DB 文件，校验通过后加入备份列表，不自动还原
- **恢复备份**：用某个备份覆盖当前数据（有二次确认）
- **删除备份**：删除不再需要的备份包（有二次确认）

## 备份列表
列表显示每个备份的文件名、创建时间、大小，按时间从新到旧排列。

## 本地备份怎么恢复
1. 进入「数据备份」，点击「上传备份」并选择本地文件
2. 上传校验完成后，在列表中找到新导入的备份（系统会重新生成文件名）
3. 点击该备份的「还原」，确认覆盖提示后执行
4. 完成后页面显示还原前自动生成的安全备份名称，需要恢复还原前状态时可使用该备份

## 容量与格式
- 上传的单个备份文件不能超过 100MB，ZIP 解压后总量不能超过 512MB 或 10000 个文件
- 仅支持审批中心兼容格式，损坏、结构不符或含非法路径的文件会被拒绝
- 服务器上已有的 ZIP 在还原时也会检查解压体积与文件数
- 生成备份未按上述容量限制截断；附件累计较大时，可能生成无法通过上传或还原校验的备份
- 附件上传上限的安装配置不改变这些备份限制

## 恢复注意
- ZIP 恢复会**整体覆盖**当前审批数据库和附件；历史 DB 文件只恢复数据库，保留当前附件
- 还原前会自动生成安全备份；如果安全备份生成失败，不会覆盖当前数据
- 切换数据失败时系统会尝试回滚；若提示回滚未完成，联系管理员检查服务器日志和安全备份
- 恢复后审批数据回到备份时刻的状态
- 请在无人操作审批时执行，避免覆盖其他人刚提交的审批数据
